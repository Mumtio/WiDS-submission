# SOLUTION OVERVIEW

The solution uses a survival-analysis-based ensemble pipeline.

Main steps:

1. Load `train.csv` and `test.csv`.
2. Create engineered wildfire risk features, including:

   * distance features
   * fire area and growth features
   * closing speed and ETA features
   * threat/urgency composite features
   * zone-based near/far indicators
   * temporal features
3. Train multiple models using cross-validation:

   * Gradient Boosting Survival Analysis
   * Cox Proportional Hazards model
   * Random Survival Forest
   * XGBoost AFT survival model, if available
   * LightGBM-based timing/calibration models, if available
4. Generate out-of-fold predictions.
5. Blend model predictions using zone-specific weights.
6. Optionally apply meta-stacking and calibration.
7. Enforce monotonicity across prediction horizons.
8. Generate the final submission file.

Prediction horizons:

```text
12 hours
24 hours
48 hours
72 hours
```

Final output columns:

```text
event_id
prob_12h
prob_24h
prob_48h
prob_72h
```
